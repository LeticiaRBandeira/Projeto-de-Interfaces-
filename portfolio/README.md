# Portfólio — Letícia Rodovalho Bandeira

Site pessoal desenvolvido para a disciplina de **Desenvolvimento de Interfaces** (Engenharia de Software · UniCEUB). Reunindo projetos acadêmicos, habilidades, radar de oportunidades de estágio e anotações de carreira.

## Como editar os dados
Todo o conteúdo pessoal (nome, textos, links, formação, habilidades e projetos) fica centralizado em `js/data.js`. Basta alterar esse arquivo para atualizar o site inteiro. Para disponibilizar o currículo para download, adicione o arquivo em `assets/curriculo.pdf`.

## Tecnologias
- HTML5 semântico
- CSS3 (variáveis de tema claro/escuro, Grid e Flexbox)
- JavaScript puro (filtros, persistência em `localStorage` e validação de formulários)

## Publicação
Configurado para rodar diretamente como site estático no GitHub Pages a partir da branch `main`.
