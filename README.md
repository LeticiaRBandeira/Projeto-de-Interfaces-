# Projeto-de-Interfaces-
Portfólio Interativo para Estudantes é um site que une duas funções, apresentar o trabalho de um estudante e orientar quem está começando na vida profissional.

A aplicação reúne uma seção de projetos com filtro por categoria, currículo com linha do tempo e habilidades, e um mural em que o visitante pode cadastrar o próprio projeto, com título, descrição, link e imagem. Também traz informações gerais sobre empresas e programas de estágio, com busca e filtro por tipo, e um guia de carreira com dicas sobre currículo, LinkedIn, entrevistas, estágio, CLT e concurso, finanças e networking. Um checklist de primeiros passos mostra o progresso do usuário.

A interface prioriza navegação clara, com menu fixo que destaca a seção atual, animações sutis ao rolar a página, tema claro e escuro, layout responsivo para celular, tablet e desktop e recursos de acessibilidade como link de salto, rótulos ARIA e respeito à preferência de movimento reduzido. O formulário de contato tem validação, e os dados do tema, do checklist e do mural ficam salvos no navegador por meio do LocalStorage.

Tecnologias: HTML5, CSS3, JavaScript, LocalStorage, Git e GitHub Pages. O desenvolvimento foi feito com a metodologia de Vibe Coding, com uso de IA documentado no relatório.
